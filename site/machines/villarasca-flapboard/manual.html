OPERATING AND MAINTENANCE MANUAL — SPLIT-FLAP BOARD CONTROL POSITION, VILLARASCA AIR TERMINAL

Overview

The FV/63 position drives and maintains the departures board in the hall of Villarasca Air Terminal: six rows of thirty-four falling flaps, moved one tooth at a time by solenoid banks, fed from a motor-generator set under the desk. The board is the product; the desk exists so that one fitter can keep it truthful. Words are composed onto the board either from the punched-tape schedule (TAPE) or by hand at the selectors (HAND).

The machine asks little and forgives less. It steps whether or not anybody reads it, a bound flap stalls the whole cascade, and the windings cook quietly if the armature ammeter is ignored. Read Section 4 before your first solo shift.

Controls

Denomination Type Duty
CONTROL SUPPLY toggle Mains to the desk: annunciators, starter coil, tape reader. Down OFF, up ON.
M-G SET STARTER guarded push Starts the motor-generator set. Dead until the GUARDIA flap is lifted; refuses while the breaker is tripped.
RUN LEVER quadrant lever FERMO/STOP — drive idle. MANUALE/HAND — compose by hand. NASTRO/TAPE — the queued timetable runs out onto the board.
ROW SELECTOR rotary, 1–6 Chooses the board row for hand setting.
FIELD SELECTOR rotary, 5 pos. Chooses the column group: DESTINATION, FLIGHT, VIA, TIME, REMARKS.
CHARACTER SETTER rotary, 37 pos. Selects the character: blank, A–Z, 0–9. Shown in the CELLA window.
SET CELL push In HAND mode, writes the selected character to the first place of the selected row and field.
TAPE FEED push Feeds the next timetable entry into the queue. CODA drum counts entries waiting; six maximum.
JAM CLEAR CRANK hold-and-turn Back-drives the cascade to free a bound flap. Hold roughly three seconds, supply ON.
OVERLOAD RESET collared push Frees the tripped breaker once the windings are below 80 °C and no flap is bound.
ALARM ACCEPT push Silences the horn and steadies the flashing window; the lamp stays lit while the fault persists.
LAMP TEST push Lights every jewel. Prove all six before trusting a dark panel.
REINDEX push Walks every cam stack home against the logical register. Clears an index error; needs the set turning.
FAULT SELECTOR rotary, 4 pos., under cover Test bench: selects the injected fault. Maintenance use only.
INJECT push, under cover Fires the selected test fault into the drive. Never with the public in the hall.

Normal operation

  1. Switch CONTROL SUPPLY ON. The SUPPLY jewel lights; the horn test relay clicks once.
  2. Lift the GUARDIA flap and press M-G SET STARTER. The M-G SET jewel lights as the set comes up to 1420 giri; the ARMATURA ammeter settles near 1 A.
  3. Move the RUN LEVER to MANUALE/HAND. Compose a trial word: choose ROW, FIELD and CHARACTER, press SET CELL, and watch the flap fall.
  4. Press TAPE FEED once for each departure to be posted. Each press queues one line of the summer timetable; the CODA drum counts them.
  5. Move the RUN LEVER to NASTRO/TAPE. The cascade empties the queue row by row; the PASSI drum totals the steps. Keep feeding the queue as the afternoon fills.
  6. To amend a word mid-service, bring the lever back to HAND, select the row, field and character, and press SET CELL.
  7. At close of traffic: lever to FERMO/STOP, then CONTROL SUPPLY OFF. The board sleeps where it stands.

Alarms

Windows flash and the horn sounds until ALARM ACCEPT is pressed; accepted windows burn steady while the fault remains.

Window Meaning Action
OVERLOAD (red) Winding temperature above 83 °C, or the set has tripped at 95 °C. Ignored, the breaker opens and the board freezes mid-word. Stop stepping; let the AVVOLG. needle fall under 80 °C; press OVERLOAD RESET.
FLAP JAM (red) The torque monitor has found a bound flap. Every attempt to step heats the windings towards the trip. Crank it free (Section 5.1) before the set cooks.
INDEX ERR (amber) The encoder poll finds flaps sitting between teeth: the board is lying to the public. TAPE mode is refused meanwhile. Run REINDEX with the set turning.

Faults and recovery

5.1 — Flap jam

You see: FLAP JAM flashing; one cell outlined dark red on the board; the ARMATURA needle kicking towards the red arc each time the cascade reaches the row; OVERLOAD following if you leave it.

  1. Press ALARM ACCEPT to silence the horn.
  2. Confirm CONTROL SUPPLY is ON (the crank needs desk power).
  3. Hold the JAM CLEAR CRANK and keep it turning about three seconds. The outline clears when the flap rides free.
  4. If the set has already tripped, wait for AVVOLG. under 80 °C and press OVERLOAD RESET.
  5. Restart the M-G set and resume with the RUN LEVER.

5.2 — Motor overheating

You see: OVERLOAD steady or flashing; the AVVOLG. needle deep in its red sector; a hot-varnish smell from the desk apron. Past 95 °C the breaker opens itself, the generator voltage dies and the board stands half-written.

  1. Bring the RUN LEVER to FERMO/STOP at once; stepping is the heat.
  2. Watch the AVVOLG. needle fall below 80 °C — the fan does this in a minute or two, longer if you ignored the first warning.
  3. Press OVERLOAD RESET. The window goes out.
  4. Restart the set and return the service to TAPE or HAND.

5.3 — Index error

You see: INDEX ERR amber; stray flaps sitting a tooth off — ROMA reading PONA; TAPE mode refused at the interlock though the cascade itself still runs.

  1. Press ALARM ACCEPT.
  2. Be sure the M-G set is running (STARTER lit, not tripped).
  3. Press REINDEX. Every cam walks home in one sweep of a few seconds.
  4. The window extinguishes; TAPE mode is released. Verify a word against the tape before resuming the service.

Specifications

Desk supply 380 V three-phase, 50 Hz, plus 24 V battery for annunciators
Motor-generator set 3 kW, 1420 giri, compound; DC side 52 V
Armature current 1 A excitation idling; 30 A full scale; sustained above 24 A not permitted
Winding limits alarm 83 °C, trip 95 °C, reset permitted below 80 °C
Board 6 rows × 34 characters; fields DESTINATION 10, FLIGHT 5, VIA 6, TIME 5, REMARKS 8
Flap register 37 positions: blank, A–Z, 0–9; cascade rate 42 falls a second
Queue capacity 6 timetable entries; feed refused when full
Jam clearing hand crank, 3 s continuous against the drive, desk supply ON
Ambient 0…45 °C, hall relative humidity to 85 %
Mass, complete console 410 kg, floor-mounted on four anti-vibration pads
