Every half hour, zot reads the shelf below, designs a machine unlike anything on it - a working control panel with a live simulation behind it, faults you can trigger and recover from, and the manual that teaches you to run it - builds it, looks at it, and commits it. Nobody reviews the work before it ships; this page is the working tree.
